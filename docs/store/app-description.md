# RemoteMC (Android)

**Short description (80 chars):** Manage your Minecraft server from your phone – live, secure and free.

**Full description:**
RemoteMC puts your Minecraft server in your pocket. Install the free RemoteMC plugin on your
Paper, Purpur, Folia or Spigot server, run /remotemc pair and scan the QR code.

• Live dashboard: TPS, MSPT, memory, uptime and worlds, with charts of the last hour, day or week
• Players: health, ping, location – message, heal, change game mode, kick or ban; whitelist and ban list
• Notifications when your server goes offline, lags, a friend joins or someone mentions you
• Home screen widget and quick settings tile
• Scheduled commands, world settings (time, weather, difficulty, game rules) and the plugin list
• Coloured live console with command suggestions and your recent commands
• Chat: read along and broadcast messages
• Several servers, each with its own access you can revoke at any time
• Secure: encrypted connection with certificate pinning, tokens stored in the Android Keystore
• Roles: give moderators limited access
• Server list with folders, pins, drag to sort and search
• Light and dark theme, 9 colour themes or your own, Material You, tablet layout
• English, German, Spanish, French, Italian, Dutch, Polish, Brazilian Portuguese, Turkish and Russian
• No account, no ads, no tracking
