| # | Funktion / Änderung | Teile | Beschreibung | Erledigt |
|---|---|---|---|---|
| 1 | Eigener Installations-Assistent | Windows | Statt des Standard-Fensters mit dem roten Anker bekommt der Windows-Installer ein eigenes Aussehen im RemoteMC-Stil (Logo, Grün/Dunkel, eigene Texte). | ☐ |
| 2 | Server-Ordner am PC | Windows | Wie am Handy: aufklappbare Ordner mit Anzahl, Server per Ziehen umsortieren und in Ordner/aus Ordnern ziehen, „In Ordner verschieben“, Ordner umbenennen/entfernen (Server bleiben). | ☑ (Teil A) |
| 3 | Ordner durch Ineinanderziehen | Handy + Windows | Zieht man in „Alle Server“ einen Server auf einen anderen, entsteht ein Ordner: Popup „Wie soll der Ordner heißen?“ mit Eingabe; „Erstellen“ legt ihn an, „Abbrechen“ schiebt den Server wieder an seinen alten Platz. | ☑ (Teil A) |
| 4 | Server und Ordner anpinnen | Handy + Windows | Server anpinnen (am PC neu) und **auch ganze Ordner** anpinnen (neu auf beiden) – angepinnte stehen oben. | ☑ (Teil A) |
| 5 | Server nebeneinander andocken | Windows | Einen Server-Tab an den Rand ziehen (links, rechts, oben, unten) oder in die Mitte (als Tab) – so sieht man mehrere Server gleichzeitig; Trennlinien verschiebbar, Anordnung bleibt gespeichert. | ☐ |
| 6 | Restliche Handy-Funktionen am PC | Windows | „Erneut koppeln“ (auch im Hinweis bei geändertem Zertifikat/entzogenem Zugang), alle Server aktualisieren, Suche mit ✕ und „Keine Treffer“; Spieler suchen und sortieren (Name/Ping/Welt), Ping-Balken, Spielmodus-Abzeichen; Konsole: „Nach unten“-Knopf und Mitlaufen pausiert beim Hochscrollen, letzte Befehle vergessen; echte Skins im Chat; Welt-Karten der Übersicht anklickbar; Verlauf-Diagramm mit Wert beim Draufzeigen; Hilfe-Seite; Willkommens-Seiten beim ersten Start; Sprache wählen; Einstellungen: Plugin herunterladen, Quellcode, Lizenzen, Hinweis; Benachrichtigung anklicken öffnet den Server, auf Erwähnungen direkt antworten; Ruhezeiten wie am Handy (still statt verworfen); Schalter „auf Widget zeigen“ am PC ausblenden. | ☐ |
| 7 | Logo ohne Hintergrund | Handy + Windows | Das bisherige Logo bleibt unverändert (Block mit Grasdeckel und >_, gleiche Farben), nur der dunkle Kasten dahinter fällt weg – in den Apps, als Windows-Symbol und in der README. Das Android-Startbildschirm-Symbol und das Play-Store-Symbol brauchen technisch einen Hintergrund und bleiben wie sie sind. | ☑ (Teil A) |
| 8 | Tabs verschieben | Windows | Server-Tabs oben in der Leiste per Ziehen umsortieren, wie im Browser; die Reihenfolge bleibt gespeichert. | ☐ |
